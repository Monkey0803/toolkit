# 工具集合网站设计规格

## 1. 产品目标

构建一个面向综合用户的轻量工具目录，帮助用户快速发现常用工具入口。首版以目录浏览体验为核心，不实现登录、后端、在线编辑或真实工具执行页面。

成功标准：

- 用户进入首屏即可理解网站用途，并能通过搜索或分类找到工具。
- 搜索和分类筛选可以叠加，结果数量和空状态清晰可见。
- 用户可以收藏工具，刷新页面后收藏仍然保留。
- 桌面端、窄屏和手机端均不出现横向溢出或不可操作控件。
- 交互控件支持键盘访问，并为动态结果提供辅助技术反馈。

## 2. 视觉方向

采用“轻量工具目录”方向：浅蓝灰画布、深墨蓝文字、低饱和蓝色辅助文本和酸橙色细节点缀。整体明快、现代、偏产品化，避免营销型大面积渐变和装饰性插画。

首屏层级：

1. 顶部品牌与轻量导航，桌面显示 About、Submit a tool、Saved 数量；手机隐藏次要链接，保留品牌和收藏入口。
2. 中央定位文案 `Small tools, big momentum.` 与一句短说明。
3. 大尺寸搜索框，作为首屏最主要的操作入口。
4. 六类分类胶囊：全部工具、文本处理、格式转换、开发辅助、图片与颜色、生成器、生活计算。
5. 工具卡片网格，显示图标字符、名称、描述、分类、标签和收藏按钮。

响应式布局：桌面三列，窄屏两列，手机单列。分类胶囊在小屏幕上横向滚动，卡片内容允许自然换行。

## 3. 技术架构

使用 Vite + React + TypeScript，保持依赖最小化，不引入第三方 UI 库或后端服务。

文件职责：

- `src/data/tools.ts`：工具分类、工具项类型和首批本地工具数据。
- `src/App.tsx`：页面骨架、搜索状态、分类状态、收藏状态和筛选结果派生逻辑。
- `src/styles.css`：颜色变量、排版、布局、交互状态、响应式规则和减少动效规则。
- `src/main.tsx`：React 应用挂载入口。

工具数据字段：

```ts
type Tool = {
  id: string;
  name: string;
  description: string;
  category: ToolCategory;
  icon: string;
  tags: string[];
};
```

首版目录使用六个分类：文本处理、格式转换、开发辅助、图片与颜色、生成器、生活计算。数据只存在前端源码中，便于后续接入详情路由或 CMS。

## 4. 交互行为

### 搜索

- 输入变化时即时过滤，不需要提交按钮。
- 匹配名称、描述和标签，不区分大小写。
- 搜索与分类筛选同时生效。
- 结果区域显示当前结果数量，并通过 `aria-live="polite"` 告知动态变化。
- 无匹配时显示明确的空状态，建议用户修改关键词或切换分类。

### 分类

- “全部工具”默认选中。
- 每次只激活一个分类。
- 分类按钮使用原生 `<button>`，以 `aria-pressed` 表示当前状态。
- 当前分类与搜索词同时显示在结果标题或辅助说明中。

### 收藏

- 每个工具卡片有独立收藏按钮，使用星标字符和可读的 `aria-label`。
- 收藏集合保存在 `localStorage`，键名固定为 `toolkit:saved-tools`。
- 收藏数量显示在导航和页面状态中。
- 首版不新增“仅看收藏”筛选页，Saved 数量仅作为持久化状态反馈，避免扩大范围。

### 卡片

- 卡片主体是暂不跳转的展示入口，不伪装成已经存在的工具执行页。
- 收藏按钮与卡片主体的交互独立，点击收藏不会触发卡片其他行为。
- 使用稳定的 `id` 作为 React `key`。

## 5. 可访问性与质量约束

- 使用 `header`、`nav`、`main`、`section` 和正确的标题层级。
- 搜索框有可见标签或等价的 `aria-label`，不能只依赖 placeholder。
- 分类、收藏和其他交互均使用原生按钮，不使用带点击事件的非语义元素。
- 动态结果数量使用 `aria-live="polite"`，空状态保持可读。
- 收藏按钮提供当前状态的可读标签，例如“收藏 JSON Formatter”或“取消收藏 JSON Formatter”。
- 颜色对比度满足普通文本可读性要求，焦点状态清晰可见。
- 使用 `@media (prefers-reduced-motion: reduce)` 关闭或缩短过渡动画。
- 不依赖 hover 才能理解或完成核心操作。

## 6. 验证方案

实现后执行：

- `npm run build`，确认生产构建通过。
- 手动验证默认列表、关键词搜索、分类筛选、搜索 + 分类叠加和空状态。
- 收藏一个工具，刷新页面，确认收藏状态与 Saved 数量仍然存在。
- 使用 Tab、Enter 和 Space 完成搜索、分类切换和收藏操作，确认焦点可见。
- 在桌面、窄屏和手机宽度检查卡片、分类条和导航是否溢出。
- 检查 `prefers-reduced-motion` 下没有强制动画。

## 7. 明确不包含的内容

- 用户登录、账号同步和云端收藏。
- 后端 API、数据库和管理后台。
- 工具真实执行逻辑或在线编辑器。
- 工具详情页、路由和站内内容管理。
- 广告、评论、评分和提交审核流程。
